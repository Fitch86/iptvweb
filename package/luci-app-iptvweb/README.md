# luci-app-iptvweb 0.2.2-rc1.1

本目录为 OpenWrt/LuCI 软件包。项目说明、安装步骤、Safari 音轨分流机制、历史版本脉络和 RC1 测试清单请参阅仓库根目录 [README.md](../../README.md)。

RC1.1 以 RC1 的 rev4.25 播放基线为基础，清理用户可见的诊断面板、能力探测按钮、TS 分析/抓包入口和播放实验开关；保留播放状态提示、正常停止/恢复操作、Safari PMT 音轨识别、MPEG Audio 独立 MP2PCM，以及 AAC/未知音轨的原生 A/V MSE 路径。

此版本增加无视频广播频道的独立音频启动、Safari TS 同步识别加固和视频画面点击暂停/继续。此版本用于测试，不应把尚未在目标设备上验证的组合视为已保证兼容。
